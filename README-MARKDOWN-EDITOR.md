# Markdown AI 智能编辑器使用指南

## 简介

这是一个基于Web的Markdown智能编辑器，支持通过本地部署的OpenAI兼容API进行AI辅助写作。

**特点：**
- 🚀 单文件HTML应用，打开即用
- 💡 AI智能补全，提升写作效率
- 📝 实时预览，所见即所得
- ⚙️ 灵活配置，满足不同需求
- 💾 本地存储，无需后端

## 快速开始

### 1. 打开编辑器

直接在浏览器中打开 `markdown-ai-editor.html` 文件即可使用。

### 2. 配置API

点击右上角的 **⚙️ 配置** 按钮，设置以下参数：

- **API 地址**：您的OpenAI兼容API端点（如：`http://localhost:11434/v1/chat/completions`）
- **API Key**：如果需要认证，填写API密钥（本地API可留空）
- **模型名称**：使用的模型名（如：`qwen`、`llama3`等）

点击 **保存配置** 按钮保存设置。

### 3. 开始写作

在左侧编辑器中编写Markdown文档，右侧会实时显示预览效果。

### 4. 使用AI补全

1. 将光标放在需要补全的位置
2. 按下 `Ctrl+E` 触发AI补全
3. 等待AI生成建议
4. 按 `Tab` 接受补全，或按 `Esc` 拒绝

## 补全粒度说明

### 输入粒度（上下文）

决定发送给AI的内容范围：

- **光标前全部内容**：发送从文档开始到光标位置的所有内容
- **当前段落**：只发送当前段落的内容
- **当前章节**：发送从最近的标题到光标的内容
- **最近500字符**（推荐）：发送光标前最近的500个字符

### 补全粒度（生成长度）

决定AI生成内容的长度：

- **句子**：生成10-30字的单个完整句子
- **段落**：生成50-150字的2-4个句子
- **章节**：生成200-400字的多个段落

## 高级配置

### 模型参数

- **Temperature**（0-2）：控制输出的随机性
  - 0.0：最确定、最保守
  - 0.7：平衡（推荐）
  - 2.0：最随机、最有创意

- **Max Tokens**：每种粒度的最大令牌数
  - 句子：50（推荐）
  - 段落：200（推荐）
  - 章节：500（推荐）

### 提示词自定义

可以自定义系统提示词和补全提示词模板，以适应不同的写作风格和需求。

**可用占位符：**
- `{CONTEXT}`：上下文内容
- `{GRANULARITY}`：补全粒度名称
- `{LENGTH_GUIDE}`：长度指导说明

### 调试模式

启用调试模式后，浏览器控制台会输出：
- API请求详情
- 原始响应内容
- 处理后的结果
- 使用的粒度和参数

## 兼容的API

1. **鲁棒的JSON解析**

## 常见问题

### Q: API调用失败怎么办？

A: 请检查：
1. API地址是否正确
2. 本地API服务是否正在运行
3. 是否存在CORS问题（建议使用同源或配置CORS）
4. API Key是否正确（如果需要）

启用调试模式可以在控制台查看详细的错误信息。

### Q: 生成的内容长度不符合预期？

A: 请确保：
1. 启用了"长度控制"选项
2. 根据需求调整Max Tokens参数
3. 检查提示词是否明确了长度要求

### Q: 如何提高补全质量？

A: 建议：
1. 提供足够的上下文（选择合适的输入粒度）
2. 调整Temperature参数（0.5-0.8之间通常效果较好）
3. 自定义提示词以适应您的写作风格
4. 使用更强大的模型

### Q: 文件保存在哪里？

A: 文件会保存到浏览器的默认下载目录。您可以在浏览器设置中更改下载位置。

## 最佳实践

1. **选择合适的粒度**
   - 写大纲：使用"句子"粒度
   - 写段落：使用"段落"粒度
   - 写章节：使用"章节"粒度

2. **优化上下文**
   - 一般情况使用"最近500字符"
   - 需要全局理解时使用"光标前全部内容"
   - 快速补全时使用"当前段落"

3. **调整参数**
   - 技术文档：Temperature 0.3-0.5
   - 创意写作：Temperature 0.7-1.0
   - 严谨内容：Temperature 0.1-0.3

4. **定期保存**
   - 养成按 `Ctrl+S` 的习惯
   - 重要内容建议备份多份
